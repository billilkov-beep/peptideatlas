## Reproducible verification

`npm run catalog:check` validates counts, exact name coverage, category coverage, substantive fields, source provenance, section citation indices, FAQ requirements, and related-profile links. The production build runs that gate before generating its artifacts.

The admin **Collection coverage** screen recalculates current represented and published coverage from the actual database. Edited or withdrawn records are preserved during catalogue upgrades, so an existing installation can intentionally differ from the bundled release.
